chatbase.kr 서비스 안내


## 서비스 소개

chatbase.kr는 내 자료로 학습한 AI 챗봇을 만들어, 코드 한 줄로 내 홈페이지에 붙일 수 있는 한국어 챗봇 서비스입니다.

- 고객 응대: 영업시간, 환불 규정, 배송 문의, 상품 안내 등
- 사내 활용: 인사 규정, 업무 매뉴얼, 복지 안내 등 직원 질문 응대

주요 특징
- 자료(텍스트/파일/웹페이지)만 올리면 챗봇 완성
- script 태그 한 줄로 사이트에 설치
- 카카오톡 채널 연동 지원
- GPT 사용료를 chatbase.kr가 부담하므로 API 키 없이 바로 시작 가능
- 본인 API 키를 등록하면(BYOK) 모델 선택·파일 학습·웹 검색이 열리고 대화 건수 제한이 없어짐
- 신용카드 없이 무료로 시작 가능


## API 키 — 무료 제공과 BYOK

Q. API 키를 꼭 만들어야 하나요?
A. 아니요. chatbase.kr가 OpenAI 사용료를 부담하므로 가입 후 키 없이 바로 챗봇을 만들어 쓰실 수 있습니다. 이 경우 모델은 gpt-5.6-luna 한 가지로 고정되고, 플랜별 월 대화 건수 한도를 적용받습니다.

Q. 그럼 내 키를 등록하면 뭐가 달라지나요?
A. 네 가지가 열립니다. (1) 모델을 직접 고를 수 있습니다. (2) 파일 학습(PDF, DOCX 등)을 쓸 수 있습니다. (3) 웹 검색이 동작합니다. (4) 월 대화 건수 제한이 없어집니다. 이때 모델 사용료는 회원님이 해당 제공자에 직접 결제하시며, chatbase.kr는 호출비를 중간에서 받지 않습니다.

Q. 왜 내 키를 쓰면 대화 건수 제한이 없나요?
A. 건수 한도는 chatbase.kr가 키를 내주기 때문에 있는 것입니다. 회원님 키로 도는 대화는 저희 원가가 들지 않으므로 건수를 제한할 이유가 없습니다.

Q. Claude나 Gemini도 키 없이 쓸 수 있나요?
A. 아니요. 무료로 제공되는 것은 OpenAI(GPT)뿐입니다. Anthropic(Claude)과 Google(Gemini) 모델은 본인 키를 등록하셔야 사용할 수 있습니다.

Q. 키를 등록하면 무료 제공 키는 못 쓰나요?
A. 둘 다 남아 있고 대시보드 > API 키 화면에서 체크 하나로 오갈 수 있습니다. 등록해두고도 평소에는 무료 제공 키로 쓰시다가, 필요할 때만 내 키로 바꾸셔도 됩니다.

Q. 키 발급이 어렵지 않나요?
A. 각 제공자 사이트에서 5분 안에 발급받을 수 있습니다. 발급받은 키를 대시보드 > API 키 페이지에 한 번만 등록하면 됩니다. 세 곳 모두 등록할 필요는 없고, 사용할 모델의 키 하나만 있으면 됩니다.
키 발급처는 다음과 같습니다.
- OpenAI: https://platform.openai.com/api-keys
- Anthropic: https://console.anthropic.com/settings/keys
- Google: https://aistudio.google.com/app/apikey

Q. 등록한 API 키는 안전한가요?
A. 회원님이 등록하신 API 키는 Fernet(AES-128) 대칭키 암호화로 데이터베이스에 저장됩니다. 평문은 어떤 시점에도 저장되지 않으며, 챗봇이 응답을 생성하는 순간에만 복호화되어 사용됩니다. 회원이 직접 삭제하거나 탈퇴하면 즉시 파기됩니다.

Q. 어떤 AI 모델을 쓸 수 있나요?
A. OpenAI(GPT), Anthropic(Claude), Google(Gemini) 계열 모델을 지원합니다. 무료 제공 키를 쓰시는 동안에는 gpt-5.6-luna로 고정되고, 본인 키를 등록하시면 그 제공자의 모델이 선택 목록에서 활성화되어 언제든 바꾸실 수 있습니다.

Q. 한도를 다 쓰면 어떻게 되나요?
A. 그 달의 남은 기간 동안 챗봇이 방문자에게 회원님이 설정하신 안내 메시지로 답합니다. 본인 OpenAI 키를 등록하시면 즉시 이어서 사용하실 수 있고, 플랜을 올리시면 한도가 커집니다. 한도는 매월 1일에 초기화됩니다.


## 시작하는 방법

1단계. (선택) API 키 등록
가입 직후 바로 2단계로 가셔도 됩니다. GPT 사용료는 chatbase.kr가 부담합니다.
모델을 직접 고르거나, 파일 학습·웹 검색을 쓰거나, 대화 건수 제한을 없애고 싶을 때만 등록하시면 됩니다.
1. 대시보드 > "API 키" 메뉴 진입
2. 사용할 제공자(OpenAI / Anthropic / Google) 카드에서 "내 키 사용" 클릭
3. 키 발급처 링크에서 새 키 발급 후 복사해 입력창에 붙여넣고 저장
등록 후에도 "무료 제공"과 "내 키 사용" 중 어느 쪽을 쓸지 체크로 고르실 수 있습니다.

2단계. 챗봇 만들기
1. 대시보드 > "새 챗봇 만들기"
2. 기본 정보 입력: 챗봇 이름, 모델 선택, 선택 사항으로 로고와 위젯 아이콘
3. 대화 설정: 인사 메시지, 시스템 프롬프트(톤·역할·금지사항), Fallback 메시지(자료에 없는 질문일 때 안내할 문구)
4. 학습 데이터 입력
5. 저장 후 미리보기 위젯에서 바로 테스트

3단계. 사이트에 임베드
1. 저장된 챗봇 페이지 하단 "임베드 코드" 섹션에서 코드 복사
2. Script 방식(권장): 한 줄을 사이트의 </body> 직전에 붙여넣으면 우측 하단에 채팅 버블이 자동 생성됩니다
3. iframe 방식: 페이지 안 특정 위치에 채팅창을 넣고 싶을 때 사용합니다
임베드 코드 예시: <script src="https://chatbase.kr/widget.js" data-bot-id="abc123" defer></script>


## 학습 자료 넣는 방법

세 가지 방법이 있습니다.
1. 텍스트 직접 입력 — 대시보드에 내용을 붙여넣기
2. 파일 업로드 — PDF, DOCX, TXT 등
3. 웹페이지 주소 입력 — 해당 페이지 내용을 읽어옵니다

FAQ, 영업시간, 환불 정책, 상품 안내, 사내 규정 등 답변시킬 내용을 자유롭게 넣으면 됩니다. 자료에 없는 질문에는 미리 설정한 fallback 메시지로 안내합니다.

파일 업로드 학습 조건
파일 업로드 학습은 세 가지가 모두 갖춰져야 합니다. (1) STANDARD 이상 플랜, (2) OpenAI 모델 선택, (3) 본인 OpenAI 키 등록. 무료 제공 키로는 파일 학습을 쓸 수 없습니다 — 업로드한 파일은 키를 발급한 계정에 저장되기 때문에, chatbase.kr의 키로는 회원님이 올리신 파일을 읽을 수 없습니다. Anthropic이나 Gemini 모델을 쓰실 때는 텍스트 또는 웹페이지 방식을 이용해 주세요.

Q. 답변이 어색한데 어떻게 개선하나요?
A. 시스템 프롬프트 보강, 학습 텍스트 추가, 모델 변경 순서로 손보면 빠르게 개선됩니다.

Q. 한국어 응답이 자연스러운가요?
A. OpenAI, Anthropic, Google의 최신 모델 모두 한국어 응답이 매우 자연스럽습니다. 시스템 프롬프트에서 말투(존댓말/반말, 공식적/친근함)를 지정할 수 있고, 자료를 한국어로 넣으면 그 톤을 따라갑니다.


## 설치와 연동

Q. 어떤 사이트에 설치할 수 있나요?
A. HTML 코드를 수정할 수 있는 모든 사이트에서 동작합니다. 카페24, 아임웹, 식스샵, Shopify, WordPress, Webflow, 노션, 자체 제작 사이트 모두 지원합니다. script 태그와 iframe 둘 다 사용 가능합니다.

Q. 정말 코드 한 줄이면 설치되나요?
A. 네. 챗봇을 생성하면 한 줄짜리 script 태그가 발급됩니다. 이 한 줄을 사이트의 </body> 직전에 붙여넣으면 우측 하단에 채팅 버블이 자동 생성됩니다. 모바일에서도 반응형으로 동작합니다.

Q. 기존 사이트 디자인이 깨지지 않나요?
A. 위젯은 Shadow DOM으로 CSS가 격리되어 있어 사이트 기존 스타일과 충돌하지 않습니다.

Q. 카카오톡 채널에도 붙일 수 있나요?
A. 네. 카카오 오픈빌더의 스킬 서버로 연결하면 카카오톡 채널에서도 같은 챗봇이 답합니다. 대시보드에서 스킬 URL과 시크릿을 발급받아 오픈빌더에 등록하시면 됩니다. 홈페이지 위젯과 카카오톡을 함께 쓸 수 있고 대화 기록도 한곳에서 확인됩니다. 카카오톡 채널 연동은 PREMIUM 이상 플랜에서 제공됩니다.

Q. 사내 매뉴얼이나 직원 교육용으로도 쓸 수 있나요?
A. 네. 고객 응대와 같은 방식으로 만들면 됩니다. 인사 규정, 업무 매뉴얼, 복지 안내 같은 자료를 넣어두면 직원이 "육아휴직 신청 절차가 어떻게 되나요?" 같은 질문을 바로 물어볼 수 있습니다. 홈페이지에 붙이지 않고 사내에 링크만 공유해도 동작합니다. 다만 링크를 아는 사람이면 누구나 이용할 수 있으니 민감한 자료는 이 점을 고려해 주세요. 사내 구성원만 쓰는 전용 챗봇 사이트가 필요하시면 ENTERPRISE 구축으로 문의해 주세요.


## 대화 기록

방문자와 챗봇이 주고받은 대화는 대시보드 > "대화 내역" 메뉴에서 모두 확인할 수 있습니다. 봇별, 세션별로 조회됩니다.

보관 기간은 플랜에 따라 다릅니다. 기간이 지난 대화는 목록에서 보이지 않습니다.
- FREE: 7일
- STANDARD: 90일
- PREMIUM: 무제한
- GLOBAL: 무제한
대화가 삭제되는 것은 아니며, 플랜을 올리시면 이전 대화도 다시 보입니다.

어떤 질문이 자주 들어오는지 확인해 학습 자료를 보강하는 데 활용할 수 있습니다.


## 회원가입, 결제, 해지

Q. 회원가입은 어떻게 하나요?
A. 이메일과 비밀번호로 가입하거나, Google 또는 Kakao 계정으로 간편 가입할 수 있습니다. 신용카드 없이 무료로 시작할 수 있습니다.

Q. 결제 수단은 무엇인가요?
A. 토스페이먼츠를 통한 카드 정기결제를 지원합니다.

Q. 자동 갱신되나요?
A. 네. 정기결제는 회원이 해지하지 않는 한 결제 주기 단위로 자동 갱신됩니다. 유료 플랜 요금에는 부가가치세가 별도로 부과됩니다.

Q. 해지하면 바로 사용이 중단되나요?
A. 대시보드에서 언제든 해지할 수 있으며, 해지하더라도 이미 결제된 주기의 종료일까지는 서비스를 계속 이용할 수 있습니다.

Q. 환불은 되나요?
A. 환불은 관련 법령 및 회사가 게시한 환불 정책에 따릅니다. 개별 상황은 hello@chatbase.kr로 문의해 주세요.

Q. 요금이 바뀌면 어떻게 알 수 있나요?
A. 요금 또는 제공 범위가 변경되는 경우 시행일 30일 전까지 서비스 내 공지 또는 이메일로 안내합니다.

Q. 세금계산서 발행이 되나요?
A. ENTERPRISE 구축 상품은 세금계산서 발행을 지원합니다. 그 외 건은 hello@chatbase.kr로 문의해 주세요.


## 개인정보와 보안

- 수집 항목은 이메일, 이름(닉네임), 비밀번호(해시 저장)입니다. OAuth로 가입하신 경우 제공자(Google 또는 Kakao)로부터 받은 프로필 이미지와 이메일을 함께 수집합니다.
- API 키는 Fernet(AES-128)으로 암호화해 저장하며, 응답 생성 시점에만 복호화됩니다.
- 회원은 대시보드 설정 페이지 또는 이메일 문의로 개인정보 열람, 정정, 삭제를 요청할 수 있습니다.
- 자세한 내용은 홈페이지 하단의 "개인정보처리방침"과 "이용약관"을 참고해 주세요.
