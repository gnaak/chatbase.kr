# ⚠️ 이 파일만으로는 부족하다. Cloudflare가 자기 robots.txt를 이 위에 얹고,
#    WAF에서 AI 봇을 실제 403으로 끊는다. 대시보드에서 두 개를 꺼야 이 파일이 산다:
#      1) Bots  →  "AI 스크레이퍼 및 크롤러 차단" 토글 OFF
#      2) Bots  →  "관리형 robots.txt" OFF
#    확인:  curl -A "OAI-SearchBot/1.0" https://chatbase.kr/ -o /dev/null -w "%{http_code}"
#
# 방침은 셋으로 나뉜다 (aeo/PROJECT.md §2):
#   검색·인용  → 허용. 이게 AEO 그 자체다
#   학습       → 허용. 랜딩은 공개 마케팅 텍스트고, 브랜드가 알려지는 게 이득이다
#   무단 수집  → 차단. 얻는 게 없다
